Google Calendar setup

Calendar access is optional. Sign-in happens in your browser; the widget never receives your Google password. You supply your own OAuth client.

  1. Create a project in Google Cloud Console.
  2. Enable Google Calendar API.
  3. Configure Google Auth Platform branding and audience. For a personal account choose External. While Testing, add your sign-in account under Audience → Test users.
  4. Under Clients create a Desktop app OAuth client and download its JSON. Web application clients are unsupported.
  5. Click Connect Google → Import OAuth JSON and sign in on the widget, select the file and authorize in the browser.
  6. Open calendar settings to choose displayed calendars. The primary calendar is initially selected. Scroll over its step label to change refresh timing.

Cloud setup reference: Google's official Calendar Python quickstart.

403 access_denied

If Google says the application has not completed verification and is limited to developer-approved testers, add the account you are signing in with to the same project's Test users list. Then retry sign-in from the widget. Managed Workspace accounts can also have administrator restrictions.

Token expiry

External applications in Testing receive refresh tokens that expire after seven days for these Calendar scopes. Production status changes those testing restrictions but does not guarantee verification or remove all account policies. See Google's token-expiration documentation. Reconnect when access expires or is revoked.

Permissions and event edits

The widget requests calendar-list read access and event access. It reads selected calendars and creates, edits or deletes events only where the account can write. Read-only calendars are labeled. All-day end dates in the form are inclusive. Calendar times use Europe/Prague; nonexistent daylight-saving times are rejected. Recurring edits affect only the selected occurrence. Full-series changes open in Google Calendar.

Private files

~/.local/share/center-desktop/ holds google-client.json, google-token.json, calendar-cache.json, settings and any pending write. Personal JSON uses mode 0600. Never commit these files. Remove access through your Google account's connected-app settings to revoke the token.

Interrupted writes

Retry the unchanged event form after a lost response. The saved event identifier prevents an additional insertion. After a restart, use Settings → Check and finish previous write before starting another event. Edits detect changes made elsewhere; refresh and reopen the event on a conflict.
