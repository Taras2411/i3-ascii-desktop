Google Календарь / центральная панель

Панель получает доступ к списку календарей и событиям. Она умеет читать, создавать, редактировать и удалять события в календарях, где у вашего аккаунта есть право записи. Вход выполняется в браузере Google; пароль панель не получает.

  1. Откройте Google Cloud Console и создайте отдельный проект, например Desktop Calendar.
  2. В библиотеке API включите Google Calendar API.
  3. В Google Auth Platform настройте приложение: название и контактный email. Для личного Google-аккаунта выберите External. На этапе тестирования добавьте свой аккаунт в Test users.
  4. В Clients создайте OAuth-клиент типа Desktop app и скачайте его JSON. Для веб-приложений нужен другой тип клиента, который здесь не подходит.
  5. На панели нажмите Подключить Google → Импортировать OAuth JSON и войти, выберите скачанный файл и разрешите доступ в браузере.
  6. В настройках календаря выберите отображаемые календари. Основной включается автоматически. События загружаются раз в 5 минут; над подписью «шаг» интервал меняется колёсиком.

Постоянное подключение

У внешнего приложения со статусом Testing refresh-токен для этих разрешений обычно истекает через 7 дней. Для постоянного личного использования переведите приложение в In production, затем при необходимости подключите его заново. Google может показать экран о непроверенном личном приложении. Корпоративные аккаунты могут требовать разрешения администратора.

Данные и отключение

OAuth-файл, токен, кеш событий и локальные задачи хранятся в ~/.local/share/center-desktop/. Доступ к каталогу разрешён только владельцу. Не публикуйте файлы google-token.json, google-client.json и кеш календаря.

Отозвать разрешение можно на странице подключений Google-аккаунта. После отзыва панель предложит войти заново.

Повторяющиеся события изменяются по одному вхождению. Для изменения всей серии используйте кнопку открытия Google Календаря. При неоднозначном ответе сети повтор сохранения не создаст дубликат; прерванную запись можно восстановить в настройках.
